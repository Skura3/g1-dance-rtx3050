## 选择你的起点

- **当前电脑重做一次**：两个环境和模型都已存在。先运行第 02 章的只读检查，跳过安装，按第 03 章在新目录 `outputs/tutorial_repro/` 中重建；按第 04 章使用新 run-name 训练。
- **新电脑从头搭建**：先保留本项目的 `tools/`、`configs/`、`envs/training/` 和经过补丁的 `third_party/`。第 02 章给出独立安装路线。只克隆上游仓库不会得到我们编写的工具。
- **仅看成果**：直接到第 05 章，原速打开 429526 步展示版，不启动训练。
- **完全随机权重学习**：看第 04 章的独立分支。它与本次成功路线不同，没有在这台 4GB 显卡上验证同等收敛效果。

## 已完成结果与证据边界

你的原视频是 720×1280、30FPS、370 帧，约 12.33 秒；本次参考动作是 616 帧、50Hz。展示版为 **429526** 步，最终可续训版为 **452376** 步。本轮由你观看后认可并决定结束，**不是所有严格误差阈值都通过**。
