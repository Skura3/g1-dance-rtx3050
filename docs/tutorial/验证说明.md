## 本次实际做过的核对

- 自动检查Markdown本地链接目标存在。
- 用 `bash -n` 检查教程全部Bash命令块；用Python AST检查其中内嵌Python代码语法。
- 从实际脚本AST提取 `add_argument`，核对教程调用的命令行选项确实存在。
- 在临时目录验证配置助手创建文件、拒绝重复实验名、原片重点采样保留、新片旧窗口禁用。
- 使用训练环境实际 `TrainConfig` 和配置覆盖器检查生成字段合法；没有实例化Trainer或训练。
- 加载归档轨迹和现有MuJoCo二进制模型，核对617个记录状态对应616步、50Hz/12.32秒、36个qpos、关节顺序及有限值。
- 验证独立播放器墙钟、暂停、恢复、重置的时间计算；没有在本次额外打开GUI。
- 核对两个冻结检查点SHA256与原manifest一致；查询训练和看护服务为inactive。

机器可读记录：[`validation.json`](validation.json)、[`helper_validation.json`](helper_validation.json)、[`playback_validation.json`](playback_validation.json)。静态检查不能证明安装下载一定成功、GUI一定可用或学习必然收敛，但可排除命令选项拼错、路径链接缺失和示例语法错误等常见问题。

## 本次没有重做的事情

没有删除或重装工作环境，没有重新联网下载大模型，没有重跑视觉重建、物理评测或长时间训练，没有启动新服务、暂停壁纸或改动现有奖励/参数。独立洁净安装清单是依据本机依赖整理的可操作路线，仍需在新机器实测；它不是经过第二台机器端到端验证的安装锁。
