## 运行与测量

第一次使用上游 run_benchmark，contact / nju_drift 分别完成 616 步，标准化回报 0.4919 / 0.4843；最大倾斜误差 39.39° / 32.97°。原始结果：outputs/nju_validation/policy_evaluation.json。

第二次独立运行用于录像，保存每一步真实物理状态并在首个终止状态结束记录，关闭自动重置。两版均正常到达片尾；每段记录包含初始状态加 616 步，共 617 个状态。没有中途写回根节点、外力或重置。控制周期 0.02 秒，真实重力 -9.81 m/s²，自由基座；未修改力矩限制。

脚部/身体相对误差会进行上游的平面位置/朝向对齐，因此不能代替绝对方向与位置检查。contact 对齐身体平均误差约 8.0 cm，但绝对身体误差约 39.4 cm。摄像机跟随机器人，直接观看时也可能低估世界坐标中的漂移。

上游失败条件只检查根高度差超过 0.25 m，或两者投影重力 z 分量差超过 0.8。纯偏航旋转不改变该重力分量，因此机器人背向参考仍可能不终止。现已增加四元数旋转误差、包裹到 ±180° 的偏航误差、位置漂移及关节 RMSE，避免将生存时间当作复现质量。

已保留上游时间约定：物理初态来自 frame 0，但 reset 的 command 更新将首个目标推进到 frame 1；录像指标使用当步更新后的参考，存在一个控制帧的目标前视。没有为改善分数调整时间轴。两次运行数值存在差异，且指标采样时刻不同；尚未完成多次重复性或多种子鲁棒性检验，不把两次差异当作算法改进。

## 4GB 显存结果

录像运行两个并行环境，GPU 总显存采样峰值 1233 MiB，最高温度 72°C；完成两条物理轨迹约 47.94 秒墙钟时间，不含视频渲染。这是推理评测，不能等同于微调训练耗时或显存。

此前完整尺寸网络 64 环境 / batch 32 的训练组件三次更新峰值 1595 MiB，仍只是短测。已有大网络权重不能套用缩小网络的旧训练配置；后续保持网络及输入维度，降低并行数/回放容量控制显存。
